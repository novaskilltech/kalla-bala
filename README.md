# بيانات موقع «كَلَّا وبَلَى»

هذا المجلد يحتوي على قاعدة البيانات الأولية للموقع التعليمي.

## الملفات

- `kalla-bala.data.json`: ملف مستقل عن إطار العمل، مناسب لأي واجهة أو API.
- `kalla-bala.data.ts`: نفس البيانات بصيغة TypeScript للاستيراد المباشر داخل Next.js / React.

## التحقق الآلي

تم التحقق من:

- إجمالي السجلات: **55**
- «كَلَّا»: **33** = 15 وقف + 18 وصل
- «بَلَى»: **22** = 13 وقف + 5 وصل + 4 الوجهان جائزان والوصل أولى
- لا توجد معرفات `id` مكررة.

## الحقول الأساسية

- `id` معرف ثابت للرابط والبطاقة.
- `word` الكلمة: كَلَّا / بَلَى.
- `sura`, `suraNumber`, `ayah` موضع الآية.
- `excerpt` المقطع القرآني المرتبط بالحكم.
- `category` أحد: `stop`, `connect`, `prefer_connect`.
- `scholarChoice` صياغة الحكم للمستخدم.
- `simpleExplanation` شرح سريع.
- `detailedExplanation` شرح أوسع للبطاقة.
- `memoryRule` قاعدة قصيرة للحفظ.
- `hasDisagreement` هل يحتاج الموضع إلى إظهار تبويب الخلاف.
- `disagreementNote` خلاصة الخلاف عند وجوده.
- `difficulty` من 1 إلى 3 لاستخدامه في الاختبارات التكيفية.
- `sourceKeys` مراجع المحتوى.

## ملاحظة علمية

البيانات مصممة لعرض **اختيار الشيخ توفيق النحاس**، لا لادعاء الإجماع. عند `hasDisagreement: true` يجب أن تُظهر الواجهة الخلاف بوضوح.

## الخطوة التالية المقترحة في الكود

استخدم `category` للفلترة والألوان الدلالية، و`difficulty` لبناء الاختبارات، و`id` لإنشاء روابط مثل:

`/ar/kalla/26/62`

أو:

`/ar/places/kalla-26-62`
